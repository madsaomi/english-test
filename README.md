# 🎓 English Level CAT Platform + Telegram Bot

Адаптивная система компьютерного тестирования уровня английского языка (**CAT — Computerized Adaptive Testing**, шкала **CEFR: A1–C2**) с единым сервером на **Python (FastAPI + aiogram 3.x)**, современным веб-интерфейсом и автоматической отправкой результатов в **Telegram**.

---

## ✨ Ключевые возможности

1. **🧠 Адаптивный алгоритм (CAT Engine)**:
   - Вопросы подстраиваются под знания кандидата в режиме реального времени: при верных ответах сложность растет, при ошибках — снижается.
   - Точное определение истинного уровня (от A1 до C2) всего за **10–14 вопросов** вместо громоздких тестов на 50 заданий.
   - Детализация по трем направлениям: **Grammar**, **Vocabulary**, **Usage**.
   - Автоматическое выявление слабых тем и генерация персональных рекомендаций.

2. **⚡ Единый сервер (FastAPI + aiogram)**:
   - Вся система работает в **одном процессе Python**:
     - Обслуживание сайта, статики и REST API (`FastAPI`).
     - Telegram-бот (`aiogram 3.x`) на асинхронном Event Loop в рамках `lifespan`.
   - **Безотказный демо-режим**: если токен бота еще не указан, сервер запускается и сайт работает на 100%, не вызывая ошибок.

3. **📱 Интеграция с Telegram**:
   - Автоматическая отправка структурированной карточки с результатами теста администратору/учителю.
   - Полная поддержка **Telegram WebApp**: можно запускать прямо из бота нажатием кнопки, при этом имя и Telegram-юзернейм подставляются автоматически.
   - Персональная отправка отчета и советов самому ученику в чат с ботом.

4. **💎 Премиальный дизайн (Glassmorphism UI)**:
   - Тёмная нео-палитра с мягким свечением и градиентами.
   - Живой индикатор предполагаемого уровня и прогресс-бар.
   - Таймер на каждый вопрос и плавная анимация карточек.
   - Поддержка горячих клавиш клавиатуры (`1-4` или `A-D`).
   - Идеальная адаптивность для мобильных телефонов и компьютеров.

5. **🤖 Папка для агентов (`agents/`)**:
   - Полная система документации для совместной работы любых AI-агентов (реестр, инкрементальный журнал сессий, карточки задач и регламенты).

## 🚀 Быстрый запуск

### 1. Установка зависимостей
Убедитесь, что установлен Python 3.10+ (протестировано на Python 3.14):
```bash
pip install -r requirements.txt
```

### 2. Настройка конфигурации (`.env`)
Откройте файл `.env` в корневой папке и укажите ваши параметры:
```ini
# Токен вашего Telegram-бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ

# Ваш Telegram Chat ID (куда бот будет присылать результаты тестов)
# Узнать свой ID можно в боте @userinfobot
ADMIN_CHAT_ID=123456789

# Порт и адрес сервера
HOST=0.0.0.0
PORT=8000

# URL приложения (локально или адрес вашего домена/ngrok)
WEBAPP_URL=http://localhost:8000
```
> *Примечание: Если оставить `BOT_TOKEN` пустым, сервер запустится в ДЕМО-режиме, сайт будет работать в браузере!*

### 3. Запуск единого сервера
```bash
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
После запуска откройте в браузере:
👉 **[http://localhost:8000](http://localhost:8000)**

  ```bash
  python -m backend.test_simulation
  ```
- **Сквозное E2E тестирование API и отправки контактов**:
  ```bash

  ```
