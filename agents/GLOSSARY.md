# 📖 Глоссарий предметной области (GLOSSARY.md)

Словарь терминов и сокращений проекта для предотвращения смысловых разночтений и галлюцинаций между AI-агентами.

---

| Термин | Расшифровка / Значение |
|---|---|
| **CEFR** | *Common European Framework of Reference for Languages* — общеевропейская шкала языковой компетенции (A1, A2, B1, B2, C1, C2). |
| **A1 / A2** | *Basic User* — начальный (Beginner) и элементарный (Elementary) уровни. |
| **B1 / B2** | *Independent User* — средний (Intermediate) и продвинутый (Upper-Intermediate) уровни. |
| **C1 / C2** | *Proficient User* — профессиональный (Advanced) и уровень владения в совершенстве (Mastery). |
| **CAT** | *Computerized Adaptive Testing* — компьютерное адаптивное тестирование, при котором сложность последующего вопроса зависит от правильности предыдущих ответов. |
| **Ability Score** | Числовой рейтинг способности ученика в системе CAT (в нашем проекте от 1.0 до 6.0). |
| **Streak** | Серия подряд идущих верных или неверных ответов, влияющая на шаг усложнения/облегчения вопросов. |
| **Distractor** | Дистрактор — неправильный вариант ответа в вопросе с множественным выбором (Multiple Choice). |
| **TMA / WebApp** | *Telegram Mini App* — веб-приложение, встроенное непосредственно внутрь Telegram и использующее `Telegram WebApp SDK`. |
| **Lifespan** | Механизм FastAPI для запуска и корректной остановки фоновых задач (в нашем проекте — polling Telegram-бота) в едином жизненном цикле приложения. |
| **Polling** | Способ работы Telegram-бота, при котором сервер сам периодически опрашивает Telegram Bot API (`getUpdates`). Не требует публичного IP при локальной разработке. |
| **Webhook** | Способ работы Telegram-бота, при котором Telegram сам присылает входящие сообщения HTTP-запросом на сервер (требует белый IP и HTTPS). |
| **Second Brain** | Концепция папки `agents/`, хранящей всю долговременную память, архитектуру, решения и правила проекта. |
