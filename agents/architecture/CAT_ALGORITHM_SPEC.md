# 🧠 Спецификация алгоритма CAT (Computerized Adaptive Testing)

Этот документ описывает математику, логику и правила подбора вопросов адаптивного движка, реализованного в `backend/cat_engine.py`.

---

## 1. Шкала способностей (Ability Scale)

Шкала сложности и рейтинга кандидата непрерывно отображается в диапазоне от **1.0 до 6.0**:

| Диапазон `ability` | Уровень CEFR | Описание уровня |
|---|---|---|
| `1.0 <= ability < 1.6` | **A1** | Beginner (Начальный) |
| `1.6 <= ability < 2.5` | **A2** | Elementary (Элементарный) |
| `2.5 <= ability < 3.5` | **B1** | Intermediate (Средний) |
| `3.5 <= ability < 4.5` | **B2** | Upper-Intermediate (Выше среднего) |
| `4.5 <= ability < 5.5` | **C1** | Advanced (Продвинутый) |
| `5.5 <= ability <= 6.0`| **C2** | Mastery / Proficiency (Владение в совершенстве) |

Стартовая точка каждого теста: **`ability = 3.0`** (уровень B1 Intermediate).

---

## 2. Формула коррекции шага (Step-Size & Streaks)

Шаг изменения способности зависит от глубины теста:
$$\text{base\_step} = \max\left(0.28,\ 0.75 \times 0.91^N\right)$$
где $N$ — количество уже отвеченных вопросов.

### Множитель серии (Streak Multiplier):
Если кандидат отвечает подряд верно (или неверно):
$$\text{multiplier} = 1.0 + \min\left(0.5,\ (\text{streak} - 1) \times 0.25\right)$$

- При правильном ответе: `ability += base_step * multiplier`
- При неправильном ответе: `ability -= base_step * multiplier`
- Значение жестко ограничивается границами: `[1.0, 6.0]`.

---

## 3. Правило выбора следующего вопроса

1. **Ротация категорий**: для равномерного охвата тем порядок строго чередуется:
   `Grammar` ➔ `Vocabulary` ➔ `Usage` ➔ `Grammar` ...
2. **Фильтрация**: исключаются вопросы, на которые кандидат уже отвечал (`asked_question_ids`).
3. **Близость сложности**: из доступных вопросов текущей категории выбираются кандидаты с минимальной разницей $|difficulty - ability|$.
4. **Рандомизация**: среди двух наиболее близких вопросов один выбирается случайным образом, что предотвращает эффект заучивания теста.

---

## 4. Критерии завершения тестирования

Тест завершается при наступлении любого из условий:
1. Достигнут лимит в **14 вопросов** (`max_questions`).
2. Достигнут порог минимум **10 вопросов** (`min_questions`) **И** дисперсия оценок за последние 4 вопроса составляет менее 0.25:
   $$\max(history[-4:]) - \min(history[-4:]) < 0.25$$
   (означает, что уровень колебаний стабилизировался и дальнейшие вопросы избыточны).

---

## 5. Расчет итогового балла (0–100)

Нормализованный балл рассчитывается по линейной интерполяции:
$$\text{score} = \text{round}\left(\frac{ability - 1.0}{5.0} \times 100\right)$$
Ограничивается диапазоном от 5 до 99 баллов.
