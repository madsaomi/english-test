## 🟢 Уже хорошо
- `correct_option` не уходит во фронтенд напрямую (`ClientQuestion` его не содержит).
- Подпись WebApp initData: HMAC-SHA256 по официальной схеме, `hmac.compare_digest`, id пользователя берётся только из подписанных данных (main.py:62-85, 367-397).
- Экспорт PII защищён `X-API-Key` + `hmac.compare_digest`, сделана константаная запись; выключен по умолчанию (503).
- HTML-экранирование всех пользовательских данных в Telegram-карточках (`_esc`).
- Rate limit на мутации + очистка бакетов + `Retry-After`.
- GC старых сессий, фиксированный банк вопросов, `time_spent` в границах, анти-автоклик (0.5s).
- Пиннинг пути статических: API маршруты регистрируются раньше `app.mount("/")`.
- Парсинг телефона строго по Узбекистану (998), формат в экспорте.
- `.env`/`data/`/`exports/` не коммитятся (проверено `git ls-files`).
