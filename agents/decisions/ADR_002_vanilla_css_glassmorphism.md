# 🏛️ ADR-002: Vanilla CSS + Glassmorphism вместо тяжелых фронтенд-фреймворков

- **ID решения:** ADR-002
- **Статус:** 🟢 ACCEPTED (Принято)
- **Дата:** 2026-09-17

---

## 1. Контекст и проблема
Интерфейс должен выглядеть ультрасовременно, дорого и технологично (*«все было красиво и точно»*), быстро загружаться в Telegram WebApp на смартфонах даже при медленном мобильном интернете (3G/4G), и не требовать сложного шага сборки `npm build / webpack` при развертывании.

---

## 2. Рассмотренные альтернативы
1. **React / Next.js / Vue SPA**
   - *Плюсы:* Компонентный подход.
   - *Минусы:* Тяжелый bundle (сотни килобайт JS), медленный старт в мобильном Telegram WebApp, необходимость сборщика Node.js на сервере.
2. **Tailwind CSS**
   - *Плюсы:* Быстрая верстка классами.
   - *Минусы:* Требует node/npm CLI для компиляции классов, загромождает разметку.
3. **Vanilla CSS + Glassmorphism Design System**
   - *Плюсы:* Мгновенная загрузка (0 мс ожидания сборки), встроенная поддержка браузером, максимальный FPS анимаций через аппаратное ускорение GPU, полное соответствие дизайн-гайдлайнам.

---

## 3. Принятое решение
Выбран **Vanilla CSS с Glassmorphism** и чистый легковесный JavaScript.  
Все стили инкапсулированы в `static/css/style.css`, все компоненты используют общие CSS-токены `:root`.
