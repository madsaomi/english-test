---

### 🔍 Что было создано и реализовано:
1. **Зависимости и окружение**:
   - `requirements.txt`: FastAPI, Uvicorn, aiogram 3.x, Pydantic, pydantic-settings, python-dotenv, aiohttp.
   - `.env.example` и `.env`: параметры для `BOT_TOKEN`, `ADMIN_CHAT_ID`, `PORT`, `WEBAPP_URL`.
   - Настроена безопасная работа в DEMO-режиме, если бот еще не создан.

2. **Банк вопросов CEFR (`backend/questions.py`)**:
   - Откалибровано 30 вопросов от A1 до C2 по направлениям: Grammar, Vocabulary, Usage.
   - Каждый вопрос содержит метаданные: уровень CEFR, точная дробная сложность (1.0–6.0), категория, тема, варианты ответов, пояснение.

3. **Адаптивный алгоритм CAT (`backend/cat_engine.py`)**:
   - Динамический подбор вопросов на основе текущего рейтинга способности `ability`.
   - Балансировка тем (Grammar -> Vocabulary -> Usage).
   - Учет серий верных/неверных ответов (streaks) для ускоренной сходимости.
   - Критерий завершения: 10–14 вопросов либо стабилизация разброса оценок.
   - Формирование итогового отчета: точный уровень CEFR, нормализованный балл (0–100), точность (%), время, аналитика по навыкам, список слабых тем и персонализированные рекомендации.

4. **Единый сервер (`backend/main.py`)**:
   - В `lifespan` FastAPI асинхронно стартует polling `aiogram 3.x`.
   - REST API эндпоинты: `/api/health`, `/api/test/start`, `/api/test/answer`, `/api/test/result/{id}`, `/api/test/submit-contact`.
   - Раздача статических файлов веб-интерфейса из `/static`.

5. **Telegram бот (`backend/telegram_bot.py`)**:
   - Команда `/start` с приветствием и кнопкой запуска Telegram WebApp.
   - Форматированные карточки результатов с прогресс-барами, баллами, контактами и слабыми темами для отправки администратору/учителю и ученику.

6. **Премиальный веб-интерфейс (`static/`)**:
   - `index.html`, `style.css`, `app.js`.
   - Дизайн: Glassmorphism, тёмная нео-палитра (глубокий сланец, индиго, бирюзовый), плавные градиенты, адаптивность для ПК и Telegram WebApp.
   - Интерактивность: живой индикатор текущей оценки сложности, таймер, горячие клавиши (1-4 / A-D), плавная анимация вариантов ответов, детальный экран результатов.

7. **Верификация и тесты**:
   - `backend/test_simulation.py`: успешно проверены 3 сценария адаптации (High -> C2, Low -> A1, Mid -> B1).
   - `backend/test_e2e.py`: пройден полный цикл от старта до завершения теста и отправки контактов через реальный HTTP-сервер.
