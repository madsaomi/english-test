### 🔍 1. Что было сделано:

1. **Дифференцированный таймер обратного отсчета (`static/js/app.js`, `static/css/style.css`):**
   - Для вопросов с выбором варианта (Q1–Q45): ровно **30 секунд**.
   - Для вопросов с текстовым вводом (Q46–Q50): ровно **35 секунд** (дополнительное время на набор слова).
   - Расчет оставшегося времени базируется на `Date.now() - questionStartTime`, что исключает замедление или заморозку таймера при сворачивании браузера.
   - При остатке $\le 5$ секунд включается красная пульсирующая подсветка (`.timer-badge.timer-warning`).
   - При истечении времени срабатывает `handleQuestionTimeout()`: автоматически фиксируется ответ (набранный текст или пропуск `selected_option = -1`), выдается виброотклик `triggerHaptic('error')` и тост «Время вышло! Переход к следующему вопросу».

2. **Бэкенд поддержка таймаутов и подсчет пропущенных вопросов (`backend/models.py`, `backend/cat_engine.py`, `backend/main.py`):**
   - В `AnswerSubmission` добавлено поле `is_timeout: bool = False`.
   - В `main.py` разрешен прием ответов с `is_timeout=True` (или `selected_option = -1`), чтобы предотвратить ошибку 400 Bad Request при истечении времени.
   - В `TestResult` добавлено поле `skipped_count: int = 0`.
   - В `CATEngine.finalize_test` рассчитывается суммарное количество вопросов, не отвеченных вовремя.

3. **Отображение пропущенных вопросов в Telegram (`backend/telegram_bot.py`):**
   - В единой карточке администратора и кандидата добавлена строка:
     `⏳ Пропущено по таймеру: X` (или `⏳ Пропусков по таймеру: 0 (все вопросы отвечены)`).
   - Результат по-прежнему отправляется строго одним цельным сообщением.

4. **Комплексная защита от копирования вопросов (Anti-Copy):**
   - В CSS запрещено выделение текста (`user-select: none; -webkit-touch-callout: none;`) на `.screen-question` и `.question-card`.
   - Заблокировано контекстное меню (`contextmenu`) на экране активного теста.
   - Заблокированы события `copy`, `cut` и `dragstart`.
   - Заблокировано событие вставки (`paste`) в инпут текстовых вопросов Q46–Q50 (слово нужно вводить руками).
   - Заблокированы горячие клавиши копирования/сохранения (`Ctrl+C`, `Ctrl+X`, `Ctrl+U`, `Ctrl+S`, `Ctrl+P`, `F12`, DevTools).

5. **Защита от скриншотов (Anti-Screenshot):**
   - Перехват клавиши `PrintScreen` (код 44) с очисткой системного буфера обмена (`navigator.clipboard.writeText('')`).
   - Защита от печати и сохранения в PDF: `@media print { html, body { display: none !important; } }`.
   - Защитный экран потери фокуса (`.test-blur-shield` + `.focus-warning-overlay`): если пользователь переключает окно или открывает утилиту создания скриншотов, карточка вопроса мгновенно размывается и блокируется с предупреждением.
   - Включено подтверждение закрытия Telegram Mini App (`tg.enableClosingConfirmation()`).

6. **Полировка интерфейса и удаление лишних элементов:**
   - Из шапки сайта (`<header>`) удалена дублирующая кнопка «Пройти тест →». В шапке остался чистый фирменный логотип и название.
   - Из подвала (`<footer>`) удалены тестовые ссылки «Конфиденциальность», «Связаться» и «Telegram». Оставлен официальный копирайт и логотип.
   - Добавлены боковые парящие гербы Stanford (`.ambient-crest-left`, `.ambient-crest-right`): плавная непрерывная анимация покачивания и дыхания (`floatAmbientLeft` / `floatAmbientRight`, 8.5s/9.5s), деликатная прозрачность, скрываются на мобильных экранах (`max-width: 1080px`).
