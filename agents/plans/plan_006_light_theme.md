## 📌 Чек-лист реализации

### ✅ Шаг 1: `:root` — светлая база (`static/css/style.css`)
- Поменять таблицу токенов (см. выше): фон, карточки, рамки, текст, тени, `--accent-cyan` (темнее), `--primary-glow`/`--border-focus` подогнать под индиго.

### ✅ Шаг 2: Убрать тёмные хардкоды в CSS (~42 места)
- Полупрозрачные белые подложки `rgba(255, 255, 255, 0.03–0.16)` → тонировки на основе чернил `rgba(28, 25, 23, ...)` (тот же уровень прозрачности — визуально «серые вставки на бумаге»).
- Тени `rgba(0, 0, 0, 0.4–0.5)` → мягкие тёплые `rgba(28, 25, 23, 0.08–0.15)`.
- Тёмные подложки: инпуты `rgba(10,14,25,.8)` → `rgba(255, 255, 255, 0.75)` (frosted, как карточки); фильтр-табы `rgba(15,20,32,.8)` → `rgba(28, 25, 23, 0.06)`.
- Контрастные тексты: `#fff` в заголовках карточек/каталога → `var(--text-primary)`; светлые пастели для текста (`#34d399`, `#fb7185`, `#a5b4fc`, `#a7f3d0`, `#c7d2fe`, `#fda4af`, `#fecdd3` и т.п.) → тёмные «чернильные» аналоги (`#047857`, `#be123c`, `#4338ca`, `#065f46`, `#9f1239` и т.п.).
- `#fff` оставить только там, где текст лежит на цветном фоне (кнопки, бейджи на градиенте, активные табы).
- `.gradient-text` → тёмный индиго-бирюзовый градиент (светлые лайловые цвета на бумаге не читаются).
- Градиенты кнопок оставить насышенными (индиго/телеграм-синий) — они и есть «чернильные» акценты на светлом.

### ✅ Шаг 3: Ambient-свечения → чистая бумага
- `static/index.html`: удалить 3 блока `<div class="ambient-glow ...">`.
- `static/css/style.css`: удалить `.ambient-glow`, `.glow-1`, `.glow-2`, `.glow-3`.
- Итог: ровный тёплый бумажный фон — в духе минимализма предыдущего плана.

### ✅ Шаг 4: Бумажная фактура и мелочи
- На `body` (или `::before` c `pointer-events: none`): 1–2 очень слабых градиента (`rgba(28,25,23,0.03)`) — едва заметная «неровность» бумаги; без внешних картинок.
- Карточки (hero/question/result/test-card): оставить `backdrop-filter: blur(20px)` → frosted glass: полупрозрачное белое стекло поверх бумаги = современный матово-прозрачный вид.
- `app.js`: не трогаем — он использует только CSS-переменные (`var(--accent-cyan)` автоматически станет темнее).
- `index.html`: инлайн-стилей с цветами нет (только ширина прогресса).
- Мобильные стили (`@media`) — только размеры, цвета не дублируются.
