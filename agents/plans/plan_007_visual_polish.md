## 📌 Чек-лист реализации

### ✅ Шаг 1: Serif-заголовки (№1) — `static/index.html` + `static/css/style.css`
- Подключить **Lora** (кириллица есть) в Google Fonts рядом с Inter/Outfit; `--font-heading: 'Lora', Georgia, serif`.
- Serif будут: `hero-title`, `catalog-title`, `result-title`, `test-card-title`, `tg-box-header h3`, `q-number`, `logo-text`.
- **Кнопки оставить sans** — добавить исключение `.btn { font-family: var(--font-sans) }` (сейчас у `.btn` стоит `var(--font-heading)`, иначе кнопки станут serif).
- `logo-badge` («CAT») — оставить sans (это плашка, не заголовок).

### ✅ Шаг 2: Вопрос и варианты как бумажный бланк (№2) — CSS + микро-правки
- `.question-text` → serif (вопрос — «строка в документе»), крупнее и с большим воздухом.
- `.options-grid` → «бланк»: убрать зазоры-карточки; рамка пунктиром сверху/снизу; варианты — строки с `border-bottom: 1px dashed` чернильным пунктиром (последний — без линии).
- `.option-key` (A/B/C/D) → serif-буква без «квадратика», чернильная; hover — подсветка строки индиго `rgba(79,70,229,0.05)` + буква индиго; selected — левое индиго-правило (`border-left`) + фон `rgba(79,70,229,0.08)`.
- Кликабельность/хоткеи/анти-чит не трогаем.

### ✅ Шаг 3: Плавная смена вопроса (№3) — `static/js/app.js` + CSS
- Новая CSS-анимация `.q-enter` (fade + лёгкий slide-up 8–10px, ~250ms).
- В `renderQuestion()`: ре-триггер анимации (`classList.remove('q-enter')` → forced reflow → `classList.add('q-enter')`) — один небольшой фрагмент, без структурных изменений.

### ✅ Шаг 4: Стильная валидация формы (№9) — HTML + JS + CSS
- Форме добавить `novalidate`; в `handleTelegramSubmit` — проверки до fetch: имя непустое (`trim`), телефон по простому паттерну `^\+?[\d\s\-()]{10,}$`.
- Ошибка: класс `.has-error` на `.form-group` → чернильно-красная рамка `#be123c` + подпись мелким текстом под полем (сообщения вставляются JS-ом, `role="alert"`); фокус на первом невалидном поле.
- `alert()` для **сетевых** ошибок оставляем (тосты — пункт 14, не в этом плане); убираем `alert` только там, где он дублировал валидацию.
- Бэкенд-валидация (400) не меняется — фронт просто раньше и красивее сообщает.

### ✅ Шаг 5: Экран успеха с анимированной галочкой (№11) — HTML + CSS

## ⚠️ Риски и меры
- Только фронтенд; API/CAT/lead store/Telegram не трогаются.
- Serif на кнопках — типографическая ошибка для современного UI, поэтому явное sans-исключение для `.btn`.
- Ре-триггер анимации через forced reflow — стандартный приём, один вызов в `renderQuestion`.
- Валидация дублирует, но не заменяет серверную (400 остаётся страховкой).
- Lora: `display=swap`, до подгрузки — fallback Georgia; рендер не блокируется.
