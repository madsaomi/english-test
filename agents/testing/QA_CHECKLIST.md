# 🧪 Чек-лист проверки качества и регрессии (QA_CHECKLIST.md)

Каждый агент перед коммитом изменений или объявлением задачи завершенной обязан провести проверку по этому чек-листу.

---

## 📋 Обязательный чек-лист:

### 1. Автоматические тесты (Бэкенд)
- [ ] Запущен тест симуляции схождения CAT алгоритма:
  ```powershell
  $env:PYTHONIOENCODING="utf-8"; python -m backend.test_simulation
  ```
  *Критерий успеха:* 3 сценария (точность 100% / 50% / 0%) на `test_general_2026` без ошибок.
- [ ] Запущен сквозной E2E тест API:
  ```powershell
  python -m backend.test_e2e
  ```
  *Критерий успеха:* Вывод `ALL END-TO-END TESTS PASSED!`.

### 2. Проверка веб-интерфейса (Frontend)
- [ ] Стартовый экран: заголовок, бейдж CAT, три карточки фич отображаются ровно.
- [ ] Кнопка «Пройти адаптивный тест» запускает сессию без задержек.
- [ ] Экран вопросов:
  - [ ] Номер вопроса инкрементируется (`Вопрос X из ~12`).
  - [ ] Индикатор уровня меняется динамически.
  - [ ] Таймер тикает каждую секунду.
  - [ ] Прогресс-бар заполняется пропорционально.
  - [ ] Горячие клавиши `1`, `2`, `3`, `4` и `A`, `B`, `C`, `D` работают.
  - [ ] Двойной быстрый клик по опциям не вызывает дублирования ответов.
- [ ] Экран результатов:
  - [ ] Большой цветной бейдж CEFR отображается корректно.
  - [ ] Полоски навыков (Grammar, Vocabulary, Usage) соответствуют процентам.
  - [ ] Темы с ошибками отображаются в красных бейджах.
  - [ ] Персональные рекомендации выводятся списком.

### 3. Интеграция с Telegram
- [ ] В Демо-режиме (без токена) форма контактов корректно обрабатывает отправку без краша сервера.
- [ ] При наличии токена карточка результата отправляется в `ADMIN_CHAT_ID`.
- [ ] Если тест открыт через Telegram WebApp — поля имени и username заполняются автоматически.
