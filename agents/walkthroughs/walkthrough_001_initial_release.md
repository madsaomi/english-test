# 🚀 Walkthrough: Релиз базовой версии платформы (TASK-001)

- **ID документа:** WT-001
- **Дата релиза:** 2026-09-17
- **Версия проекта:** 1.0.0

---

## 🎯 Что было достигнуто:
1. Запущен полнофункциональный адаптивный тест английского языка.
2. Реализован единый сервер Python (FastAPI + aiogram 3.x), объединяющий сайт и Telegram-бота.
3. Проведены интеграционные и симуляционные тесты:
   - High Scenario (100% верных ответов) -> сходится к **C2** (99 баллов).
   - Low Scenario (0% верных ответов) -> сходится к **A1** (5 баллов).
   - Mid Scenario (смешанные ответы) -> сходится к **B1** (45 баллов).
4. Запущен и проверен локальный сервер на порту 8000:
   - Главная страница `GET /` отдает 200 OK.
   - `POST /api/test/start` инициализирует сессию.
   - `POST /api/test/answer` динамически рассчитывает уровень.
   - `POST /api/test/submit-contact` принимает контактные данные.
5. Зафиксированы и решены 3 бага:
   - BUG-001 (Pydantic v2 validation error)
   - BUG-002 (WinError 10048 port re-binding)
   - BUG-003 (PowerShell cp1252 UnicodeEncodeError)
